**PROJECT OVERVIEW**
This project analyzes the sales performance of a Pizza restaurant, focusing on key metrics such as revenues, orders, sales proportion ang quantity sold.
The analysis was conducted to identify the overall sales performance and provide insights into the customer ordering patterns.

**KEY PERFORMANCE METRICS**
Total Revenue : $817.860.05
Total Orders : 22,351
Average Order Value : $38.31
Total Quantity Sold : 49,574
Average Quantity per Order : 2 Pizzas
